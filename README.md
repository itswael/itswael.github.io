# itswael.github.io

This repository hosts the compiled, static build of Mohammad Wael's personal portfolio site, served via GitHub Pages at [itswael.github.io](https://itswael.github.io).

## About

The contents of this repository (`index.html`, `assets/`, `screenshots/`) are a generated build output — they are **not** hand-edited. The site is built and deployed automatically by a GitHub Actions workflow in the [portfolio-frontend](https://github.com/itswael/portfolio-frontend) repository, which is the actual source code (React + Vite) for the portfolio.

To make changes to the site, edit [portfolio-frontend](https://github.com/itswael/portfolio-frontend) and push to its `master` branch; the CI workflow rebuilds the site and publishes the output here.
